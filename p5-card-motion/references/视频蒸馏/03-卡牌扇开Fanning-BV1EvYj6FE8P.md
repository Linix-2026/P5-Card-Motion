### 【设计意图】
「扇开」是手牌浏览/选择姿态：整副牌绕一个枢轴呈扇形铺展，每张牌有独立的间距与抬升，使全部卡牌同时可见、可点。它与 M3 的「持握弧面」语义不同——弧面是战斗中的持握（中间拱起），扇开是浏览时的展开（绕枢轴旋转分布）。

### 【效果拆解】
| 层 | 视觉职能 | 驱动源 | 参数与成本 |
|---|---|---|---|
| 索引归一化 | 手牌 0..n-1 索引 → 居中参数（同 M3 centerOffset） | 数据（卡牌数） | 一次除法 |
| 间距曲线 | 曲线控制每两张牌的角度/水平间距 | 索引 | 查表或函数 |
| 抬升曲线 | 曲线控制每张牌相对枢轴的抬升量 | 索引 | 同上 |

### 【机制原理】
字幕原话提炼：**「创建手牌并从 0 到 1 索引卡片，根据手牌数量，用曲线控制间距和抬升」**。数学拆解：
1. `t = i / (n - 1)` ∈ [0,1]，居中化为 `u = t*2 - 1` ∈ [-1,1]；
2. **角度（间距）**：`rot = u * spreadAngle/2`——等角扇形；若用曲线（如 `sign(u)*pow(abs(u), k)`）则中段疏、边缘密（或反之），k>1 边缘加速摊开；
3. **抬升**：枢轴位于手牌下方，每张牌沿自身旋转后的 Y 轴偏移 `lift = f(u)`（常见 `cos` 形：两端低、中间高，或边缘微抬防穿模）；
4. 2D 下甚至不需要真旋转层级——直接 `translate(cx + R·sin(rot), pivotY - R·(1-cos(rot)))` 即把「绕枢轴的圆周位置」展开为 x/y（小角度时近似 `x≈R·rot, y≈R·rot²/2`，退化为二次曲线，与 M3 抛物线殊途同归）。

### 【引擎注记】
原视频用 Godot 3D 卡片对象绕枢轴排布（参考用）；2D Canvas 用 translate+rotate 等价，无需 3D。

### 【p5 移植映射】
| 原方案组件 | p5.js 2.x 等价物 | 注意点 |
|---|---|---|
| 3D 模型绕枢轴旋转 | `translate/rotate`，枢轴置于卡底下方 | 先平移到枢轴再 rotate 再上移 R |
| 引擎曲线资源 | 内联函数 `fanCurve(u, k)` | 比动画曲线资源更透明可调 |
| 索引 | 数组下标 i | 与 M2 状态键、M4 两遍绘制完全兼容 |

```js
// p5.js 2.x 实例模式骨架：扇形手牌（≤24 行核心）
function fanLayout(i, n, opt){                       // opt: {pivotX, pivotY, radius, spread, curve}
  const u = n === 1 ? 0 : (i / (n - 1)) * 2 - 1;    // [-1,1]
  // 间距曲线：k=1 等角；k>1 边缘加速摊开
  const ang = Math.sign(u) * Math.pow(Math.abs(u), opt.curve ?? 1) * opt.spread / 2;
  const x = opt.pivotX + opt.radius * Math.sin(ang);
  const y = opt.pivotY - opt.radius * (1 - Math.cos(ang)); // 圆周抬升，两端自然下探
  return { x, y, rot: ang };
}
// 绘制：push → translate(x,y) → rotate(rot) → 卡面以「底边贴枢轴」的局部原点绘制 → pop
// 动画接入 M1：把 x/y/rot 作为目标值，dampApproach 逼近，换牌/抽牌即自动平滑重排
```

**参数表**：
| 参数 | 参考默认 | 调大/调小 |
|---|---|---|
| spread 总张角 | n≤5：0.9 rad；n=10：1.6 rad | 大→摊得开但边缘卡斜视严重 |
| radius 枢轴距离 | 约 2.2×CARD_H | 大→弧平缓；小→拥挤高耸 |
| curve 指数 k | 1（等角）～1.4 | 大→中段聚拢、边缘甩开 |

**时码锚点**：短视频，核心句位于中段「根据手牌中的卡片数量，使用这些曲线来控制间距和抬升」（精确秒数 `未验证`）。

**模块归并**：新模块 **M11**。布局函数与 M3 同签名风格（输入 i,n → 输出 cx,cy,rot），可直接替换 M4 编排层的布局调用；M3 与 M11 由「场景语义」切换（战斗持握 ↔ 浏览扇开），动画状态字典 M2 无需改动。
