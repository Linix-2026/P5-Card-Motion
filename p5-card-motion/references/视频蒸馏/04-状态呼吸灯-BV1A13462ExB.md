### 【设计意图】
卡牌的「状态」是玩家每秒都在读的信息（杀戮尖塔2 四态：**可用 / 不可用 / 激活 / 危险**）。用静态颜色太弱、用弹窗太吵——呼吸灯让描边框以心跳节律**向外扩散并淡出、多层错峰叠加**，玩家用余光即可感知状态，且不同状态只换配色与频率，语义零学习成本。

### 【效果拆解】
| 层 | 视觉职能 | 驱动源 | 参数与成本 |
|---|---|---|---|
| 基础白描边框 | 与卡牌等大的描边框（动画载体） | 静态 | 1 个圆角描边 |
| 扩散波 | 边框向外扩散（scale↑ + alpha↓）的循环 | 时间（相位循环） | 每层 1 个 rect |
| 多层错峰叠加 | 同一扩散动画按频率复制几份、相位错开 | 时间 | 3–4 层；字幕明示「按频率叠加几份，层叠在一起」 |
| 状态配色 | 四态换颜色/速度：可用=柔和常态、不可用=灰暗停摆或极慢、激活=明亮加速、危险=红色急促 | 状态（数据驱动） | 仅参数差异 |

### 【机制原理】
- **扩散波 = 单个相位变量**：`p = (frameCount*speed + phaseOffset) mod 1`；`scale = 1 + p*maxExpand`、`alpha = (1-p)*maxAlpha`——一个波从贴边扩散到外扩并消失；
- **多层错峰**：N 层各取 `phaseOffset = j/N`，同一时刻总处在扩散的不同阶段，视觉上形成连绵「呼吸」而非单次脉冲；
- **状态即参数表**：呼吸频率（危险态快、可用态缓）、颜色（危险红、激活金、可用白/金、不可用灰）、层数——全部数据驱动，渲染函数只有一份（这与 M0「数据契约驱动渲染」纪律一致）；
- **组件独立性**：视频强调该效果作为独立节点/脚本挂载到任意卡牌节点——映射到 p5 即**纯函数 `drawStatusBreath(cardW, cardH, state, time)`**，在卡面局部系内调用，不持业务状态。

### 【引擎注记】
原视频 Godot 4：Panel 节点描边 + 挂载脚本调参（参考用，不移植节点概念）。

### 【p5 移植映射】
| 原方案组件 | p5.js 2.x 等价物 | 注意点 |
|---|---|---|
| Panel 描边动画 | 圆角 `rect` noFill + stroke | 在卡牌局部系内，跟随 M6 倾斜零成本 |
| 脚本参数化 | 状态表 `STATE_PRESETS` 传入 | 配色走 cFill/cStroke（硬约束 #4） |
| 节点组件 | 独立纯函数 | 不依赖 M8 卡面内部结构 |

```js
// p5.js 2.x 骨架：四态呼吸灯（≤26 行），在卡牌局部系（原点=卡心）内调用
const BREATH_PRESETS = {
  playable: { hue:[240,208,96],  speed:0.0009, layers:3, expand:10, alpha:46 },
  unplayable:{ hue:[110,110,110],speed:0.0003, layers:2, expand:5,  alpha:22 },
  active:   { hue:[240,208,96],  speed:0.0020, layers:4, expand:14, alpha:60 },
  danger:   { hue:[230,70,70],   speed:0.0030, layers:4, expand:14, alpha:66 },
};
function drawStatusBreath(state, time){
  const q = BREATH_PRESETS[state] || BREATH_PRESETS.playable;
  p.push(); p.noFill();
  for (let j = 0; j < q.layers; j++){
    const ph = (time * q.speed + j / q.layers) % 1;       // 错峰相位
    const grow = ph * q.expand;
    p.stroke(q.hue[0], q.hue[1], q.hue[2], (1 - ph) * q.alpha);
    p.strokeWeight(2);
    p.rect(-CARD_W/2 - 3 - grow, -CARD_H/2 - 3 - grow,
           CARD_W + 6 + grow*2, CARD_H + 6 + grow*2, 8 + grow);
  }
  p.pop(); // 描边类效果用默认 BLEND；如需辉光可改 ADD 并立即复位（硬约束 #5）
}
```

**参数表**：
| 参数 | 可用 | 不可用 | 激活 | 危险 | 调大/调小 |
|---|---|---|---|---|---|
| speed（相位/ms） | 0.0009 | 0.0003 | 0.0020 | 0.0030 | 大→急促警示 |
| layers | 3 | 2 | 4 | 4 | 多→连绵但成本线性增 |
| expand | 10 | 5 | 14 | 14 px | 大→扩散远 |
| alpha 峰值 | 46 | 22 | 60 | 66 | 暗底场景不超过 80 防喧宾夺主 |

**时码锚点**：四态列举在前段；实现段「新建等大白色描边框 → 向外扩散动画 → 按频率叠加几份 → 调参层叠」（精确秒数 `未验证`，AI 字幕无时间轴）。

**模块归并**：新模块 **M12**。挂载于 M4 管线（卡面绘制之后、金框之前或之后按层级决定）；`state` 应由宿主经 M0 注入点提供（建议向 M0 注入点表追加 `getCardPlayState(card)→'playable'|'unplayable'|'active'|'danger'`）。
