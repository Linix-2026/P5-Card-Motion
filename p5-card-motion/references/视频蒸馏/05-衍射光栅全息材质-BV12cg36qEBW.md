### 【设计意图】
回答「全息箔为什么看起来绚丽又混乱」的物理本质，并给出工程界面对「渲染器做不到」时的**三档造假策略**。对 p5 的价值不是搬 3D shader，而是：① 获得材质分层的正确心智模型，让 M7 的每一层都有物理依据；② 学到「精确/均衡/快速」三档取舍如何映射 Canvas 2D 的品质预算。

### 【效果拆解】（物理层 → 视觉层）
| 物理事实（字幕明示） | 视觉表现 | 对 M7 的指导 |
|---|---|---|
| 微观等距沟槽（约发丝 1/40 宽）迫使光波相长/相消干涉 | 单一光源被**克隆几十次**（实验中 49 次），成「棘刺」光束 | 当前 M7 只有 1 条主光带；**升级＝多道偏移虹彩带** |
| 不同波长在不同角度干涉分离 | 越远离中心越拉成彩虹；只在特定视角可见 | 每道克隆带的**色相随偏移角递增**，而非共享 baseHue |
| 沟槽间距增大→克隆更多 | 虹彩密度可调 | 用「道数/道间距」参数映射沟槽密度 |
| 全息≠珠光漆 | 珠光只是简单二色视角偏移；全息是多反射分裂 | 警惕把「双色渐变」误当全息（M7-b 简化版的定位应自觉降级为「珠光」） |

**三档造假方案（工程取舍精华）**：
| 档位 | Blender 做法 | 代价/缺点 | Canvas 2D 同构档位 |
|---|---|---|---|
| 精确 | OSL 波动光学脚本 | 颗粒/无法降噪/CPU 数分钟一帧 | 无对应（2D 无波动求解器）——放弃 |
| **均衡** | 1 个光泽 + 混 4 色 × 偏移法线角度，**同一件事重复 30 次** | 不算快但最通用 | **M7-pro：N 道（5–9）偏移虹彩带，每道色相按角度递增** |
| 快速 | 不响应光照的「涂上去的颜色」，预定义光源 | 不响应环境/第二光源 | **M7 现状**：固定光带 + 鼠标代理视角；非交互场景用 sin 自漂（M7-b） |

### 【机制原理】（引擎无关）
- **光栅方程直觉**：克隆光出现在 `sin θₘ = m·λ/d`（m＝级次，λ＝波长，d＝沟槽间距）——工程近似只需「第 m 道带的偏移角 ∝ m、该道色相由 θₘ 决定」；
- 角度驱动色相等价于 HSB 空间：`hue_m = (baseHue + m * hueStep + viewAngle * hueSens) mod 360`；
- 强度包络：中央级次最亮、向外衰减（sinc² 形），2D 用 `alpha_m = peak * (1 - |m|/M)` 近似；
- 视角代理：继续沿用 M7 的鼠标归一化（`mouseNormX/Y`）作为 θ——这套「鼠标＝视角」的映射在物理叙事下被二次验证是正确的。

### 【引擎注记】
原视频 Cycles OSL / 30 个光泽着色器混合 / 涂色三方案（参考用）；本蒸馏仅取「多级次克隆 + 角度分色 + 三档预算」思想，不涉及任何渲染器节点。

### 【p5 移植映射】
| 原方案组件 | p5.js 2.x 等价物 | 注意点 |
|---|---|---|
| 30 个偏移光泽着色器 | **N 道 ADD 混合偏移描边光带**（循环复用同一条绘制路径） | 道数是主要成本，建议 5–9 封顶 |
| 波长→角度分离 | 道级次 m 映射 hueStep 增量 | 用 HSB colorMode，M7 已验证 |
| 法线角度偏移 | 沿光带法线 `m*spacing` 平移 | 与 V2.0 粗斜线同法线数学，但此处为精细光栅 |
| 光照不响应的涂色版 | M7/M7-b 现状 | 保留为低档 |

```js
// p5.js 2.x 骨架：M7-pro 多级次衍射带（在卡牌局部系内，约 28 行）
function drawDiffractionBands(cardS, cx, cy, rot, isHovered, frame){
  const orders = isHovered ? 7 : 5;          // 克隆光道数（沟槽密度感）
  const spacing = 7;                          // 道间距 px ↔ 光栅沟槽密度
  const hueStep = 26;                         // 每级次色相差（波长分离强度）
  p.push(); p.blendMode(p.ADD); p.noFill();
  p.colorMode(p.HSB, 360, 100, 100, 100);
  // 视角代理：鼠标沿对角线投影（沿用 M7 逆变换得到的 mouseNormX/Y）
  const view = (mouseNormX + mouseNormY) * 0.5;
  for (let m = 0; m < orders; m++){
    const sign = m % 2 ? 1 : -1;             // 中央两侧对称
    const mm = Math.ceil(m / 2) * sign;      // 0, ±1, ±2, ±3…
    const off = mm * spacing + view * 26;
    const a = (1 - Math.abs(mm) / (orders/2)) * (isHovered ? 52 : 30); // sinc² 包络近似
    const hue = (frame * (isHovered ? 1 : 0.5) + mm * hueStep + view * 80) % 360;
    p.stroke((hue + 360) % 360, 70, 95, Math.max(0, a));
    p.strokeWeight(2.2);
    p.push(); p.translate(off * 0.707, -off * 0.707);  // 沿光带法线
    p.rect(-CARD_W*cardS/2, -CARD_H*cardS/2, CARD_W*cardS, CARD_H*cardS, 10); // 描边光道
    p.pop();
  }
  p.colorMode(p.RGB, 255); p.blendMode(p.BLEND); p.pop();
}
// 与现有 M7 关系：本函数替换/叠加于 M7 的「光带层」之上；光栅像素层、噪点层照旧保留。
```

**参数表**：
| 参数 | 默认 | 调大/调小 |
|---|---|---|
| orders 克隆道数 | 悬停 7 / 静态 5 | 大→更接近真实光栅（49 次不可行）；成本线性 |
| spacing 道间距 | 7px | 小→虹彩密（细沟槽）；大→疏 |
| hueStep 级次色差 | 26° | 大→彩虹分裂强烈；小→偏珠光 |
| view 视角灵敏度 | 80 | 大→一转卡面颜色剧变 |

**时码锚点**（AI 字幕无秒轴，按叙事段）：单光源 49 次克隆段 / 双缝干涉相长相消段 / 波长分离成彩虹段 / Cycles 无法分裂反射段 / 三方案（OSL→30 着色器→涂色）对比段。精确秒数 `未验证`。

**模块归并**：**M7-pro（增强层，非新模块）**。品质档位对应：低＝M7-b（珠光/自漂）、中＝M7 现版（单光带全息）、高＝本方案（多级次衍射）。降级时按道数 9→5→3→1 砍，最后退化为 M7-b——与 08 文档「装饰先于反馈」一致。
